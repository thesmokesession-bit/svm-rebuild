# SvM Rebuild

Mac and Windows builds. Get the newest version from Releases on the right side of this page.

Windows: download SvM_Rebuild_Windows.zip, extract it, and run SvM_Rebuild.exe. The steps are in the zip.

Mac: download SvM_Rebuild_Mac.zip, unzip it, and open the app. The steps are in the zip.

The game checks this page for updates when it starts.
